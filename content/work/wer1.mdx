## Context

WeR1 is a music streaming product. I joined as a senior React Native engineer to own playback, the part of the app people feel most.

## Problem

Off-the-shelf players could not give the team the control it needed over buffering, caching and background playback. The app was also still on the old React Native architecture, which made native audio work slow to build and harder to keep stable.

## Approach

- **Built a custom audio player library** in 3 months, with a typed JavaScript API over native playback on Android and iOS.
- **Led the migration to the New Architecture and Expo 53**, moving native modules to TurboModules and UI to Fabric in steps that kept releases going.
- **Designed offline-first audio caching** so tracks keep playing on weak networks, built to hold up at 100K+ concurrent streams.
- **Moved the codebase to TypeScript strict mode** and fixed the type holes it surfaced.

## Outcome

- A playback engine the team owns end to end, shipped in one quarter.
- **35% fewer runtime errors** after the strict-mode migration.
- A modern React Native base that new features can build on.
